# Egon

3D Minecraft-Style Sandbox Engine

## About

Egon is a browser-based voxel sandbox engine in the spirit of Minecraft:
a procedurally generated blocky world you can explore, mine and build in,
rendered in real time in the browser.

## Status

Early development. The `main` branch currently holds documentation only —
the engine source lives on the `3d-minecraft-style-sandbox-engine-f378d`
branch and has not been merged yet.

## Tech stack

- **TypeScript** and **React** for application and UI code
- **Three.js** for 3D rendering
- **Vite** for the dev server and production build
- **Tailwind CSS** for styling
